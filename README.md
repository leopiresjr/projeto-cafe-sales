# Projeto Cafe Sales

Projeto de Análise Exploratória de Dados desenvolvido com Python, NumPy, Pandas e Git/GitHub.

## Base de dados

- Dataset: Dirty Cafe Sales
- Fonte: Kaggle
- Objetivo: realizar diagnóstico, limpeza, transformação e análise exploratória dos dados.

## Tecnologias

- Python
- NumPy
- Pandas
- Git
- GitHub
